# CampusCare — Campus Complaint Management System

A C++17 subject project with a connected web frontend. The C++ backend manages complaint records, Room No., automatic priority assignment, timestamps, and status updates in `complaints.txt`.

## Quick Start (Windows)

Double-click **`build_and_run.bat`** in the project root. It automatically stops any old `complaint_server.exe` process, compiles the latest C++ code, and launches the server at **http://localhost:8080**.
